DUNTA TAXI v5 — FOTOS DE PERFIL + ÍCONES REAIS

1. Execute o ficheiro supabase_schema.sql inteiro no SQL Editor do Supabase.
2. Em Authentication > Providers > Email, desative Confirm email para o cadastro entrar imediatamente.
3. O cadastro agora exige uma foto de perfil para passageiro e motorista.
4. A foto é guardada no Storage no bucket público avatars, numa pasta com o ID do utilizador.
5. Quando o passageiro pede uma corrida, a foto do passageiro é enviada no pedido e aparece no painel do motorista.
6. Quando o motorista aceita, a foto do motorista aparece para o passageiro.
7. A foto também aparece no perfil e pode ser alterada em Conta > Alterar foto.
8. Os ícones de transporte e interface principais usam Font Awesome: carro, táxi, mota, utilizador e outros.
